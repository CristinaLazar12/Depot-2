# Depot

Depot is an e-commerce web application built with Ruby on Rails.

This project was developed while working through *Agile Web Development with Rails*. It was created as a learning project to practice Ruby on Rails development and understand how a full-stack Rails application is structured and built.

## Features

- Product catalog
- Shopping cart
- Cart item management
- Order processing
- User authentication
- Product management
- Administrative functionality
- Support request management

## Tech Stack

- Ruby
- Ruby on Rails 8
- SQLite
- Active Record
- Hotwire / Turbo
- Stimulus
- Tailwind CSS
- HTML
- Git / GitHub

## What I Learned

Through this project, I practiced:

- Building a full-stack application using Ruby on Rails
- Understanding and applying the MVC architecture
- Creating Active Record models and associations
- Implementing CRUD operations
- Working with RESTful routes and controllers
- Building a shopping cart and order workflow
- Implementing user authentication
- Working with Hotwire, Turbo, and Stimulus
- Managing application data with a relational database
- Writing and running automated tests
- Using Git and GitHub for version control

## Installation

Clone the repository:

```bash
git clone https://github.com/CristinaLazar12/Depot-2.git
cd Depot-2
```

Install the dependencies:

```bash
bundle install
```

Set up the database:

```bash
bin/rails db:prepare
```

Start the Rails server:

```bash
bin/rails server
```

Then open `localhost:3000` in your browser.
